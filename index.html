Curso: Start Base FiveM

1. Como Startar sua Base (Do zero)

A) Artefatos: Baixe a versão mais recente dos artefatos do FiveM e coloque na pasta artifacts.
B) A Base: Extraia os arquivos da sua base (vRP ou Creative) na pasta principal.
C) Banco de Dados: Abra o XAMPP ou HeidiSQL, crie uma database e importe o arquivo .sql que vem na base.
D) Server.cfg: Abra o arquivo com o VS Code e coloque sua License Key (gerada no Keymaster) e sua Steam API Key.
E) Ligar: Clique duas vezes no run.bat ou start.bat. Se o console ficar verde, deu certo!

2. Como Adicionar Novos Scripts

1. Pegue a pasta do script que você baixou (ou gerou aqui na Vida IA).
2. Coloque ela dentro da pasta resources do seu servidor.
3. Abra o seu server.cfg e adicione a linha: ensure nome_do_script.
4. Dê um restart no servidor ou digite refresh e start nome_do_script no console do F8.

Mestre em Programação FiveM

Como Colocar Mapas

1. Mapas usam arquivos .ymap.
2. Crie uma pasta (ex: meu_mapa).
3. Dentro dela, crie uma pasta chamada stream.
4. Jogue o .ymap dentro da stream.
5. Crie um fxmanifest.lua básico na pasta do mapa e dê ensure no cfg.

Como Adicionar Carros

1. Carros Add-on vêm com .ytd e .yft.
2. Coloque esses arquivos na pasta stream do seu script de carro.
3. Os arquivos de configuração (handling.meta, vehicles.meta) ficam na pasta principal do script.
4. Certifique-se de que o nome da pasta do carro é o mesmo que você usará para spawnar.

Setar ADM e Grupos

Para se setar como dono, você deve ir no banco de dados, na tabela vrp_users (ou users) e encontrar seu ID. Depois, na tabela de grupos/permissões, adicione seu ID ao grupo 'Dono' ou 'Admin'.
Dica: No console do servidor, você também pode digitar: addgroup ID Dono (dependendo da sua base).
