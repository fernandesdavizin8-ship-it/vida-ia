Curso: Como Programar sua Cidade FiveM

Parabéns por se tornar VIP! Aqui está o guia essencial para dominar sua base.

🚀 Passo 1: Como Startar sua Base

1. Baixe os artefatos do FiveM e sua base (vRP/Creative).
2. Configure o arquivo server.cfg: coloque sua License Key e o Steam API Key.
3. Para ligar, execute o run.bat ou start.bat.
4. Importante: Verifique se o banco de dados (MySQL/HeidiSQL) está ligado antes de abrir o servidor.
