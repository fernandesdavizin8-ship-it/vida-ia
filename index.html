Curso: Como Programar sua Cidade FiveM

Parabéns por se tornar VIP! Aqui está o guia essencial para dominar sua base.

1. Entendendo a Estrutura

Toda cidade FiveM roda sobre um framework (vRP, vRPex ou Creative). O coração da cidade é a pasta resources.

2. O segredo da LUA

FiveM usa a linguagem LUA. Você precisa entender dois lados:
• Client: Tudo que acontece na tela do jogador (menus, efeitos, sons).
• Server: Tudo que mexe no banco de dados (dinheiro, itens, permissões).

3. Conectando com a Vida IA

Use a Vida IA para gerar a base do código, mas sempre leia o arquivo fxmanifest.lua para garantir que o script seja carregado corretamente pelo servidor.

Dica de Ouro:

Nunca edite scripts com o servidor ligado sem testar antes localmente. Use o comando ensure [nome_do_script] no console para atualizar mudanças em tempo real.
