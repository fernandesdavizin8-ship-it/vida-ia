Curso: Start Base FiveM

1. Como Startar sua Base (Do zero)

A) Artefatos: Baixe o FXServer mais recente. Crie uma pasta server e coloque os arquivos lá.
B) Pasta Data: Crie uma pasta server-data onde ficará seu server.cfg e a pasta resources.
C) Banco de Dados: Instale o HeidiSQL e o MariaDB/MySQL. Crie uma database (ex: vrp) e importe o arquivo .sql da base.
D) Configuração: No server.cfg, configure a conexão do banco e coloque sua License Key do Keymaster.

2. Adicionar Scripts e Tradução

Adicionar: Jogue a pasta do script em resources e adicione ensure nome_da_pasta no cfg.
Traduzir: A maioria dos scripts tem uma pasta lang ou arquivos cfg.lua. Procure pelas mensagens entre aspas e traduza para o português.

3. Configurar Webhooks (Discord)

Para receber logs no Discord (entradas, saídas, mortes, baús):
1. No Discord, vá em Configurações do Canal > Integrações > Webhooks.
2. Crie um novo Webhook e copie a URL.
3. No script de logs da sua base, procure por webhook = "SUA_URL_AQUI" e cole o link.

Mestre em Programação FiveM

1. Mapas e Otimização

Instalação: Coloque o .ymap na pasta stream.
Otimização: Mapas muito pesados causam queda de FPS. Use ferramentas como o GIMS Evo ou 3DS Max para reduzir o número de polígonos e otimizar as texturas antes de subir para o servidor.

2. Resmon e Performance

Abra o console do F8 e digite resmon 1. Se um script estiver acima de 0.10ms, ele está pesado.
Dica: Aumente o tempo dos loops (Citizen.Wait) de scripts que não precisam rodar a todo momento para economizar processamento.

3. NUI (Interfaces)

Interfaces bonitas usam HTML, CSS e JS.
A comunicação entre o jogo e a interface é feita via SendNUIMessage (Lua para HTML) e RegisterNUICallback (HTML de volta para o Lua).

4. Permissões vRP/Creative

Em bases vRP, as permissões ficam no cfg/groups.lua.
Verifique se o script pede vRP.hasPermission(user_id, "perm.nome") e se você tem essa permissão adicionada ao seu grupo no banco de dados.

Conclusão Master

A chave para ser um mestre em programação é entender a lógica. Não apenas copie e cole scripts; tente ler o código e entender o que cada função faz. Use a Vida IA para tirar dúvidas sobre funções específicas e criar protótipos rápidos de sistemas complexos.
